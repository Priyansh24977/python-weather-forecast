# Python Weather Forecast System

A Python-based weather forecasting application that fetches current weather conditions and daily forecasts for a city using the Open-Meteo API.

## Features

- Search weather by city name.
- Fetch current weather conditions.
- Display daily weather forecasts.
- Retrieve weather data using a public API.
- Handle API requests using Python.

## Technologies Used

- Python
- Requests
- Open-Meteo API
- Geocoding API

## How It Works

1. Enter the name of a city.
2. The application finds the city's geographical coordinates.
3. It fetches weather information from the Open-Meteo API.
4. The weather data is displayed to the user.

## Installation and Setup

**1. Clone the repository**

```bash
git clone https://github.com/Priy ansh24977/python-weather-forecast.git
```

Replace the repository URL above with your actual GitHub URL if needed.

**2. Open the project folder**

```bash
cd python-weather-forecast
```

**3. Install dependencies**

```bash
pip install -r requirements.txt
```

**4. Run the application**

```bash
python main.py
```

## API Used

[Open-Meteo](https://open-meteo.com/) — a weather API that provides current conditions and forecast data.
